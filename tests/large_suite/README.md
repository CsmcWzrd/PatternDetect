# PatternDetect generated large suite

This directory is generated by `tests/generate_large_suite.py`.
The cases intentionally reuse fake logs while varying rotation count, component name, pattern count, pattern section length, fanout, and chain depth.

## Coverage

- cases: 1000
- fake log sets: 100
- components: 100
- pattern count range: 5..10
- chain depth range: 1..10
- fanout range: 0..9
- pattern step range: 1..10
- rotation count range: 0..10
- log line count range: 300..10000

Run from the project root after building PatternDetect:

```sh
python3 tests/run_large_suite.py --binary ./build/patterndetect
```
